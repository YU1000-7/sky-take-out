## 并行开发规则

1. 先按 `docs/api.md` 定义 DTO 和 VO，再写 Controller 与页面。
2. 每个人在独立 `feature/` 分支开发，合并前自测并提交 PR。
3. 表字段和接口字段以 `docs/api.md`、`sql/init.sql` 为共同契约。
4. 公共代码有修改需求时，先在群内说明，避免多人同时改基座。
